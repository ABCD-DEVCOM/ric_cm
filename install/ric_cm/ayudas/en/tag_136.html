ID RiC-A36
Name Record Set Type
Definition A broad categorization of the type of record set.
Domain Record Set
Specifications

For legacy purposes, this attribute is the equivalent of the Level of Description element in ISAD(G) (3.1.4) except for the value "item," which equates to the record or record part entity in RiC-CM.

May be extended to categorize types of record set that have not traditionally been considered archival.
Extensibility May be extended with any number of specific attributes.
Repeatability Not repeatable
Value schema Controlled value
Scope May be used to distinguish natural and human constructs.
