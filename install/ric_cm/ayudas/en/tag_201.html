ID RiC-R001
Name is related to Inverse relation : is related to
Domain/Range Thing Thing
Cardinality M to M
Definition The most generic relation, is related to, connects any RiC-CM entity (thing) to any other RiC-CM entity.

This relation is symmetric.

Scope Notes Can be used in order to record a current or past connection between any RiC entity. Should be used only if it is not possible to specify the nature of the relation more precisely.
Examples Princeton Ethiopic Manuscripts [record set] is related to Princeton University [agent] [en]

Princeton Ethiopic Manuscripts [record set] is related to Miracles of Mary [record] [en]
