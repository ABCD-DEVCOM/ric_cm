ID RiC-R020
Name has or had main subject Inverse relation : : is or was main subject of
Domain/Range Record Resource Thing
Cardinality M to M
Definition Connects a record resource to a thing that is or was its main subject.
Scope Notes Use for specifying, for example, that a personal file (record set) has a person as its main subject, in order to help end users retrieve the main archival resources about that person.
