ID RiC-R044
Name is agent associated with agent Inverse relation : is agent associated with agent
Domain/Range Agent Agent
Cardinality M to M
Definition

Connects two agents.

This relation is symmetric.
Scope Notes Use only if it is not possible to specify a narrower agent to agent relation, for example has or had work relation with.
